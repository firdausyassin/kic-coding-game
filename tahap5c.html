Sumber Cahaya & Syarat IF

Sains Tahun 2 mengajar kita bahawa tanpa sumber cahaya, mata kita tidak dapat melihat sebarang objek dalam gelap.

Gunakan Format Logik Bersyarat:

Anda perlu membuat pengesahan situasi sebelum bertindak:
if (ruang == "gelap") { pasang("suar") }

💡 Tanda `==` bermaksud kita sedang menyemak adakah ruang itu benar-benar gelap. Pastikan ejaan dan simbol anda betul!
💎✅

Cahaya Membawa Harapan!

Tahniah! Syarat IF anda tepat. Dengan memasang suar bercahaya, peneroka berjaya mengelak batu penghalang dan menjumpai harta karun!
