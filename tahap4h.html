Loop Pelbagai Arahan

Satu gelung (Loop) tidak terhad kepada satu arahan sahaja. Anda boleh menyumbat seberapa banyak arahan yang anda mahu ke dalam kurungan kurawal { }.

Peraturan Penting:

Jika terdapat lebih daripada satu arahan, anda **WAJIB** meletakkan koma bertitik (;) untuk memisahkan arahan tersebut.

✅ Betul: ulang(3) { bumi.sejat(); awan.hujan() }
❌ Salah: ulang(3) { bumi.sejat() awan.hujan() }
