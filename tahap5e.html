Terminal Makmal
(Misi 5E - Zon 1)

Cecair misteri sedang diuji. Kertas litmus akan menukar warnanya bergantung pada sifat kimia cecair tersebut.

Berdasarkan warna yang dikesan, gunakan logik if untuk mengesahkan status asid atau alkali!

Pangkalan Data Litmus:
kertas == "merah" -> sahkan("asid")
kertas == "biru" -> sahkan("alkali")

Format Kod:
if (kertas == "merah") { sahkan("asid") }

Ujian Sifat Bahan

Sains Tahun 3 mengajar kita cara membezakan asid dan alkali menggunakan Kertas Litmus.

Panduan Penulisan Kod If:

Jika Kertas Litmus bertukar Merah, bahan tersebut adalah Asid.
if (kertas == "merah") { sahkan("asid") }

Jika Kertas Litmus bertukar Biru, bahan tersebut adalah Alkali.
if (kertas == "biru") { sahkan("alkali") }

Perhatikan warna yang tertera di skrin penderia sebelum memberikan arahan sahkan!
