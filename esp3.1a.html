Buku Manual: Litar 3.1A (Potentiometer)

Pemasangan dibahagikan kepada 2 fasa. Sila rujuk koordinat dengan teliti.

    Fasa 1: Kedudukan Asas & Rel Kuasa

  1. 1.0) Pengawal Mikro (MCU) ESP32: [ Lubang 1B - 15J ].
    Nota: Port USB mesti menghala ke luar.
  2. 2.0) PEMBUMIAN (GND): Tarik wayar hitam dari [ Lubang 2A ] ke Jalur Biru (-).
    SEBELAH KIRI papan sahaja (seperti dalam kurungan Oren). Jangan guna jalur kanan!
  3. 3.0) REL VOLTAN (3V3): Tarik wayar Merah dari [ Lubang 1A ] ke mana-mana lubang di Jalur Merah (+).
    SEBELAH KIRI papan sahaja (seperti dalam kurungan Ungu). Jangan guna jalur kanan!

    Fasa 2: Pendawaian Komponen

  1. 1.0) Perintang (Resistor) 220Ω: [ Dari Lubang 19A ke Jalur Biru (-) ]
    PENTING: Hujung dawai kedua bebas dicucuk pada mana-mana lubang di sepanjang Jalur Biru (-) (seperti dalam kurungan Oren). Jangan guna jalur kanan!
    Tarik wayar isyarat LED (Pin D2) dari [ Lubang 4A ] ke [ Lubang 18A ].
  2. 2.0) PENDAWAIAN TOMBOL (Pusing Kanan = Laju):
    • Wayar Kiri (Kuasa): Tarik dari [ Lubang 24A ] ke Jalur Merah (+).
    • Wayar Tengah (Analog): Tarik dari [ Lubang 26A ] dan cucuk ke Pin D4 di [ Lubang 5A ].
    • Wayar Kanan (Pembumian/GND): Tarik dari [ Lubang 28A ] ke Jalur Biru (-).
    PENTING: Hujung dawai kedua bebas dicucuk pada mana-mana lubang di sepanjang Jalur Merah (+) (seperti dalam kurungan Ungu).
  3. 3.0) KOMPONEN LED: Pacak kaki panjang (+) di [ Lubang 18C ], kaki pendek (-) di [ Lubang 19C ].
  4. 4.0) POSISI POTENTIOMETER: Pacak 3 kakinya di lajur E. Tekan kuat-kuat! Kaki Kiri di [ Lubang 24E ], Tengah di [ Lubang 26E ], Kanan di [ Lubang 28E ].
