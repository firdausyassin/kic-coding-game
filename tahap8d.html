Terminal Sinkronisasi
(Misi 8D)

Bina jambatan hologram data dari menara kunci_a ke kunci_b dan pindahkan data tersebut ke dalam kunci B.

Konsep Menyalin Data (Copy):
Anda boleh menyamakan nilai B dengan A menggunakan tanda sama dengan (=).

Arahan:
Untuk memastikan Data B dan Data A adalah sama, taipkan:
kunci_b = kunci_a
Arahan Diterima: Sinkronisasi data menari A ke menara B diperlukan!

Gaung Siber

Sistem: Membaca pangkalan data kunci...
0000
kunci_a
----
kunci_b
🚙

🔄 Pemindahan Data Variabel

Dalam pengaturcaraan, anda boleh menyalin (copy) nilai dari satu pembolehubah ke pembolehubah yang lain!

Bagaimana ia berfungsi?

Data di dalam kunci_a sedang bergerak terlalu pantas untuk ditaip secara manual. Untuk menyalin nilainya tepat pada masanya, gunakan kod ini:

kunci_b = kunci_a

Komputer akan melihat nilai terkini di dalam kunci_a dan memasukkannya ke dalam kunci_b secara automatik!
🚙📡

Sinkronisasi Lengkap!

Tahniah! Anda telah berjaya menyalin data antara dua pembolehubah berbeza tanpa perlu menaip nombor secara manual. Jambatan data telah dibina dan Rover selamat melintas!
