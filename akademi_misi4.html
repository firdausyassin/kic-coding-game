📘 Panduan Misi 4

Taipkan logik bersyarat ini di dalam kurungan bilik void loop(). Berhati-hati dengan ejaan huruf besar, huruf kecil, dan pastikan kurungan penutup '}' ada di penghujungnya!

int pinLED = 13; int pinButang = 12; void setup() { pinMode(pinLED, OUTPUT); pinMode(pinButang, INPUT); } void loop() { if (digitalRead(pinButang) == HIGH) { digitalWrite(pinLED, HIGH); } else { digitalWrite(pinLED, LOW); } }
