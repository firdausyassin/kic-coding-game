stesen.tembak_laser() | stesen.buka_pintu()

Formula Arahan (Taip penuh):
if (objek == "meteor") {
  stesen.tembak_laser()
} else {
  stesen.buka_pintu()
}

Logik Bersyarat Dua Hala (If-Else)

Dunia tak selalunya ada satu pilihan. Dengan else, komputer tahu apa tindakan "Plan B" jika syarat pertama tidak ditepati!

Misi Anda:

Sistem radar mengesan salah satu daripada dua objek rawak ini:
• ☄️ Meteor (Ancaman)
• 🚀 Kapal (Kawan)

Tuliskan skrip if-else sepenuhnya dalam terminal supaya stesen dapat bertindak dengan pintar tanpa mengira apa jua objek yang datang!
