Misi 3: Isyarat Menyalakan LED

"Akhirnya! Pintu pinLED sudah bersedia. Kini tiba masanya untuk mengepam kuasa elektrik ke dalam litar."

Tugas pin 13 (OUTPUT) kini jelas. Tetapi ia masih belum melepaskan sebarang kuasa. Untuk menghidupkan LED, kita perlu menulis arahan kuasa (Tulis Digital).

Di dalam bahasa C++, HIGH bermaksud 'Kuasa Penuh (On)', manakala LOW bermaksud 'Tutup Kuasa (Off)'.

Di manakah patut ia ditaip?
Oleh kerana ini adalah tindakan operasi, ia mesti diletakkan di dalam bilik void loop() supaya ia sentiasa berjalan.

Klik butang Panduan Misi di atas untuk melihat contoh kod lengkap menyalakan LED.

📘 Panduan Misi 3

Masukkan arahan melepaskan kuasa (HIGH) di dalam kurungan beralun bilik void loop(). Pastikan huruf W adalah huruf besar, dan perkataan HIGH juga huruf besar.

int pinLED = 13; void setup() { pinMode(pinLED, OUTPUT); } void loop() { digitalWrite(pinLED, HIGH); }
