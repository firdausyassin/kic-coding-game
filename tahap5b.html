Terminal Keputusan
(Misi 5B - Zon 2)

Objek sedang diimbas. Gunakan if untuk memeriksa jumlah bucu objek tersebut berdasarkan imejnya.

Tulis syarat yang tepat untuk melepaskan objek masuk ke dalam Pintu Kebal!

Data Analisis Pengimbas:
Mengimbas objek...

Contoh Kod Kelulusan:
if (bentuk.bucu == 0) { lepaskan("bola") }
if (bentuk.bucu == 4) { lepaskan("kaset") }
Sistem Pintu Kebal dikunci. Menunggu kelulusan bersyarat.

Kenali Bucu Objek & Syarat IF

Setiap objek mempunyai sifat bucu yang berbeza. Bucu adalah tempat pertemuan garis atau penjuru yang tajam.

Panduan Kiraan Bucu:

🏀 Bola: Mempunyai 0 bucu.
📼 Kaset: Mempunyai 4 bucu.
🛡️ Pelindung: Mempunyai 5 bucu.

Periksa skrin analisis, kenal pasti objek tersebut, dan berikan akses menggunakan kod:
if (bentuk.bucu == X) { lepaskan("nama_objek") }
🔓✅

Akses Dibenarkan!

Tahniah! Anda berjaya menggunakan operator perbandingan == dan syarat if untuk mengecam objek dengan tepat. Objek telah disimpan ke bilik kebal.

💥❌

Akses Ditolak!

Objek dimusnahkan akibat ralat identiti.
