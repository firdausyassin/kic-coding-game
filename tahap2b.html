Parameter Berangka (Kuantiti)

Kurungan () di hujung fungsi pengaturcaraan berfungsi sebagai 'bekas' untuk kita memasukkan data kuantiti sebagai sasaran robot.

Cara Menggunakan Parameter:

1. Kira betul-betul ada berapa batang bunga layu 🥀 di atas batas.
2. Gantikan perkataan 'kuantiti' di dalam kod dengan nombor tersebut (Tanpa tanda petik!).
3. Jika anda menaip robot.siram(2), robot cuma siram 2 bunga terawal sahaja, bakinya mati.
4. Awas! Jangan terlebih siram parameter, nanti kebun akan banjir! 🌊
🤖🌻

Kebun Mekar Berjaya!

Hebat! Anda telah menguasai input Parameter Angka. Robot berjaya memproses nombor sasaran yang anda berikan dengan sangat tepat!

🌊

Misi Gagal!

Ralat logik pada angka input anda. Kebun telah dibanjiri atau pokok mati kekeringan.
