Penjaga gol bersedia! Gunakan logik Else If untuk menewaskan pergerakannya:

1. Jika keeper ke "kiri", rembat ke kanan.
2. Jika keeper ke "kanan", rembat ke kiri.

Contoh Sintaks:
if(keeper=="kiri"){rembat.kanan()} else if(keeper=="kanan"){rembat.kiri()}

🧠 Panduan Logik Else If

Kali ini kita ada 2 syarat yang perlu disemak menggunakan else if (Jika Tidak, Jika...). Tulis kod di bawah:

if (keeper == "kiri") {
  rembat.kanan()
} else if (keeper == "kanan") {
  rembat.kiri()
}

Tip: Ruang kosong (space) tidak penting, yang penting ialah ejaan dan kurungan { } yang betul!
