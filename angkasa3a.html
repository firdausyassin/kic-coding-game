♾️ Panduan Gelung While

"While" bermaksud Selagi. Komputer akan mengulang arahan di dalam kurungan { } beribu-ribu kali dalam satu saat, sehinggalah syarat dihentikan.

Salin kod automatik ini:

while (radar == "bahaya") { kapal.tembak() }
🌌
