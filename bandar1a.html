🚑 Arahan Bersyarat (IF)

Selamat datang ke Zon 2! Di sini kita akan mula menggunakan otak komputer untuk membuat keputusan berstruktur menggunakan blok IF.

Bagaimana ia berfungsi?

Sintaks pengaturcaraan sebenar memerlukan 2 elemen utama:
1. Syarat (Condition): Ditulis di dalam kurungan biasa ( )
2. Tindakan (Action): Ditulis di dalam kurungan beralun { }

Contoh: Jika ada ambulans, maka berikan lampu hijau.
if (ambulans) { lampu.hijau() }
