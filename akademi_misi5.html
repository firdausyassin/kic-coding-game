Misi 5: Deria Halus (Analog)

"Kita gantikan suis butang biasa dengan Sensor Cahaya LDR. Sensor ini mampu mengukur tahap kecerahan kawasan sekeliling!"

Tidak seperti suis yang hanya faham ON(1) atau OFF(0), pin Analog boleh membaca nilai nombor dari 0 hingga 4095.

Dalam misi ini, kita arahkan otak ESP32 supaya membaca nilai cahaya matahari (analogRead). Jika nilainya kurang dari 1000 (Malam), lampu LED akan menyala automatik!

Buka Panduan Misi untuk melihat struktur kod yang tepat.

📘 Panduan Misi 5

Arahkan ESP32 untuk 'membaca' memori pinLDR menggunakan analogRead. Taipkan struktur ini di dalam bilik void loop().

nilaiCahaya = analogRead(pinLDR); if (nilaiCahaya < 1000) { digitalWrite(pinLED, HIGH); } else { digitalWrite(pinLED, LOW); }
