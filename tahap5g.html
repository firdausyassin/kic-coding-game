Penilaian Isi Padu

Dalam Sains dan Matematik Tahun 2, kita mengukur tahap isipadu menggunakan perkataan seperti 'penuh' atau 'separuh'.

Panduan Kod Bersyarat:

Tunggu sehingga air di dalam tangki mencecah garisan amaran dan penderia menunjukkan status "penuh".

Gunakan format syarat ini untuk menghentikan aliran dengan pantas:
if (isipadu == "penuh") { tutup_paip() }

💡 Trik: Taip kod dengan teliti! Anda boleh buka Panduan ini untuk menghentikan masa (PAUSE) seketika jika anda terlupa format ejaan.
