Terminal Penggodam
(Misi 8C)

Memori lama anda telah dikesan sebagai "penceroboh". Tulis semula (overwrite) data tersebut kepada "pekerja" supaya pintu terbuka!

Memori Semasa (Bahaya!):
status = "penceroboh"

Tugas Anda (2 Baris Arahan):
1. Isytiharkan semula: status = "pekerja"
2. Imbas memori baru: sistem.imbas(status)
AMARAN: ID Penceroboh dikesan. Bersedia untuk hapuskan sasaran...

📝 Menulis Semula Data (Overwriting)

Di dalam komputer, pembolehubah (variable) boleh ditukar nilainya pada bila-bila masa. Komputer hanya akan mengingati nilai yang paling terakhir!

Walaupun sistem asal telah meletakkan status = "penceroboh", anda boleh menggodamnya dengan menaip status = "pekerja" di baris baru.

Data lama akan terpadam, dan data baru akan diambil alih! Selepas menukar status, hantar nilai tersebut ke pengimbas pintu menggunakan fungsi sistem.imbas(status).
